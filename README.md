# Studio Itta

Web kadeřnického a kosmetického studia **Studio Itta**, Ve Smečkách 28/595, Praha 1.

Statický web bez build kroku — otevřete `index.html` v prohlížeči a funguje.

## Struktura

| Soubor | Obsah |
|---|---|
| `index.html` | hlavní stránka (hero, služby, o studiu, prostory, ceník, dárkový poukaz, tým, kontakt) |
| `galerie.html` | fotogalerie studia s lightboxem |
| `assets/site.css` | design systém a styly pro obě stránky |
| `assets/site.js` | interakce sdílené oběma stránkami (menu, scroll efekty, záložky ceníku) |
| `assets/galerie.js` | lightbox fotogalerie |
| `assets/*.jpg` | fotografie |

## Úpravy

Barvy, typografie a rozestupy jsou v CSS proměnných na začátku `assets/site.css` (blok `:root`).
Změnou několika hodnot se přebarví celý web.

Texty se editují přímo v `index.html` a `galerie.html` — jsou členěné komentáři podle sekcí.
